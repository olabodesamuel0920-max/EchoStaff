EchoStaff Widget QA Testing

This isolated local page serves to verify the behavior of the embeddable EchoStaff AI chat widget.

How to test this page:
  • Option A (Dynamic URL parameter): Append the widget public key to the URL as a query parameter. For example, load the page on whichever dev port Next.js uses: http://localhost:3000/test_widget.html?key=YOUR_PUBLIC_KEY
  • Option B (Manual Edit): Open public/test_widget.html in your editor, locate the script tag placeholder, and paste your public key in data-echostaff-widget.
